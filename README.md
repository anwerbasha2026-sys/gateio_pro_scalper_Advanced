# Gate.io Pro Scalper — Multi-Strategy Smart TP & Trailing SL Engine (Kivy Edition)

نسخة **Kivy** المطوّرة (`v1.0.5`) من تطبيق **Gate.io Pro Scalper** المخصصة للرفع على **GitHub** (لتشغيلها على الكمبيوتر أو تحويلها تلقائياً إلى تطبيق أندرويد **APK** عبر **GitHub Actions + Buildozer**) للعمل الكامل على واجهة **[Gate.io API v4](https://www.gate.com/docs/developers/apiv4/)**.

## التحديثات والمميزات الرئيسية
- **التحكم الكامل بنطاق الفحص من الواجهة**:
  - حقل **عدد العملات (`5` إلى `1500`)** للتحكم بعدد أزواج Spot الأعلى سيولة المفحوصة في كل دورة.
  - حقل **أدنى سيولة 24h ($)** (الافتراضي `50000$`) لاستبعاد العملات ضعيفة السيولة.
- **محرك القنص متعدد الاستراتيجيات (4 استراتيجيات قابلة للتفعيل/التعطيل بشكل مستقل)**:
  1. **اتجاه صاعد + تجميع (`EMA 9/21/200 + VWAP`)**: الاستراتيجية الأصلية مع تأكيد الفريمات الأعلى `15m` و `1h` وفلاتر الفوليوم و`RSI` و`MACD`.
  2. **انفجار بولينجر (`Bollinger Squeeze Breakout`)**: رصد ضغط نطاق البولينجر واختراق الحد العلوي بشمعة صاعدة مع انفجار في حجم التداول وفوق `VWAP` و`EMA50`.
  3. **ارتداد القاع والتشبع البيعي (`RSI Oversold Bounce`)**: اقتناص الارتدادات السريعة بعد وصول `RSI(14)` دون `35` أو ملامسة البولينجر السفلي مع شمعة انعكاس خضراء وارتداد مؤشر `RSI` للأعلى.
  4. **تقاطع الزخم السريع (`EMA 9/21 Cross + StochRSI`)**: التقاط التقاطع الإيجابي المبكر بين `EMA9` و`EMA21` مع تأكيد `StochRSI (%K > %D)` وفوق `VWAP` وزيادة الفوليوم.
- **بوابة أمان موحدة لجميع الاستراتيجيات**:
  - فحص ضغط دفتر الأوامر (`Order Book Pressure`) عبر [`/api/v4/spot/order_book`](https://github.com/gateio/gateapi-python/blob/master/docs/SpotApi.md) وفحص السبريد وحالة الزوج الفورية (`trade_status == tradable` واستبعاد `st_tag`) قبل تنفيذ أي شراء.
- **إدارة الصفقة الذكية (Pro TP/SL)**:
  - تأمين الصفقة التلقائي واليدوي على نقطة الدخول (`Break-Even`)، الوقف المتحرك (`Trailing Stop Loss`)، البيع الجزئي 50% عند `TP1`، والإغلاق الفوري بسعر السوق (`Market IOC`) أو الإغلاق الإجباري المحلي.

## محتويات المشروع للرفع على GitHub
- `main.py`: الكود الكامل للتطبيق بواجهة Kivy المتجاوبة (تعمل على الهاتف والكمبيوتر).
- `NotoSansArabic-Regular.ttf`: خط عربي مدمج لضمان ظهور النصوص العربية بشكل سليم على جميع الأنظمة وأندرويد.
- `buildozer.spec`: ملف إعدادات Buildozer لبناء ملف الـ APK (`org.gateioproscalperadvanced`).
- `requirements.txt`: المكتبات المطلوبة للتشغيل المباشر.
- `.github/workflows/build-apk.yml`: ملف البناء التلقائي عبر GitHub Actions لاستخراج ملف الـ APK مباشرة من GitHub.
